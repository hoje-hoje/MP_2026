# 동아리 제공 캐릭터 시트

- 원본: 동아리가 Pinterest에서 받은 픽셀 캐릭터 시트 (게시물에 사용 가능하다고 적혀 있었음). 원작자·원래 팩 이름은 확인되지 않음.
- `tools/sprites/clean_sheet.py` 로 흐릿한 JPG를 원래 픽셀 크기로 되돌리고 배경을 지워 다시 뽑음.
- chars: 플레이어 캐릭터 16종 / animals: 장식 동물 / monsters: 균열 몬스터(예정) / walk*: 흰 기본 캐릭터 걷기 동작
- ⚠ 원작자가 확인되면 라이선스를 다시 확인할 것. 저장소가 공개이므로 문제가 생기면 이 폴더를 지운다.
