# 찾아야 하는 작은 그림 목록 (같이 찾기)

창·화면 같은 큰 UI 말고, 게임 안에 들어가는 **작은 도트 그림**만 모았어요.

## 찾을 때 규칙
- **시점**: 위에서 비스듬히 내려다보는 탑다운 (지금 게임과 같은 시점)
- **크기**: 16×16 또는 32×32 도트가 제일 좋아요 (아이콘은 16×16, 땅에 놓는 건 32×32)
- **배경**: 투명 PNG, 아니면 단색 배경 (지울 수 있게)
- **한 세트로**: 같은 사람이 그린 묶음(아이템 팩)에서 많이 고를수록 그림체가 맞아요
- **저작권**: itch.io·OpenGameArt에서 **무료(CC0 또는 상업 무료)** 표시가 있는 것. 링크도 같이 적어 주세요
- 찾으면 그림 + 링크를 보내 주면 색을 맞춰서 넣어요

검색어 예: `pixel art item icons 16x16`, `top down crafting icons`, `pixel fish icons`, `pixel furniture top down`
