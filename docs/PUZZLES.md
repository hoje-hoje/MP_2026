# 수학 문제 넣는 법

제단에서 E를 누르면 나오는 문제들이에요.

## 파일
- **진짜 문제:** `server/puzzles.local.json` (서버 컴퓨터에만 두고 **저장소에 올리지 않음**. `.gitignore`에 들어 있음)
  - 저장소가 공개라서, 여기에 올리면 학생들이 GitHub에서 답을 볼 수 있어요.
  - 서버를 켠 채로 파일을 고치면 5초 안에 자동으로 반영돼요.
- **샘플:** `server/puzzles.sample.json` (진짜 파일이 없을 때 쓰임, 예시 1개)
- **미리보기용:** `client/puzzles.preview.json` (서버 없는 미리보기에서만 씀. 답이 보이므로 샘플만)

## 형식
```json
{
  "puzzles": [
    {
      "id": "p001",
      "type": "미적분",
      "level": 2,
      "question": "f(x)와 g(x)는 서로 역함수이고 ∫₁^g(x) f(t)dt = x³ 일 때 g(2)의 값을 구하여라.",
      "image": "assets/puzzles/p001.png",
      "answer": ["7"]
    }
  ]
}
```

| 칸 | 설명 |
|---|---|
| `id` | 겹치지 않는 이름 (p001, p002 …). 한 사람은 같은 문제를 한 번만 맞힐 수 있어요 |
| `type` | 기하 · 대수 · 확통 · 미적분 · 수열 · 논리 중 하나. 그 속성 영토의 제단에서 먼저 나와요 |
| `level` | 난이도 1~3 (지금은 표시만, 나중에 보상 차이) |
| `question` | 문제 글. 그림이 있으면 그림 설명으로 쓰여요 |
| `image` | (선택) 문제 캡처 그림. `client/assets/puzzles/` 에 넣고 경로를 적어요 |
| `answer` | 정답 목록. 띄어쓰기는 무시하고, 숫자는 값으로 비교해요 (7 = 7.0 = 14/2). 다른 표기를 허용하려면 여러 개 적어요 |

## 규칙 (지금)
- 우리 땅과 붙은 **중립 영토** 제단: 맞히면 그 땅을 점령
- **우리 영토** 제단: 맞히면 병력 +10
- 제출할 때마다 행동력 1 (하루 10, 자정 초기화). 틀려도 들어요
- 같은 속성 문제가 없으면 아무 문제나 나와요
