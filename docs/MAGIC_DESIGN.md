# 마법석 스킬 트리 — 마법이 게임에서 하는 일 (초안)

- 칸 하나 = **마법석 하나**. 이름은 `불 마법석 Ⅰ`처럼 **속성 + 로마 숫자(단계)**.
  - Ⅰ = 1단계, Ⅱ = 2단계(둘 중 하나만), Ⅲ = 궁극기
- 마법석을 칸에 **끼우면** 그 마법을 배움. Ⅰ은 3개까지 끼워 강화(효과 커짐).
- 지금은 **플레이어끼리 싸우기 꺼짐** → 모든 마법은 **생활·채집·나라 돕기** 효과로 시작.
  "싸움 켜면" 칸은 나중에 싸움(X1)을 켤 때 덧붙일 효과.
- 키: 배운 마법 중 2개를 골라 **R / F** 키(패드는 동그라미 버튼)에 걸어 둠.
- 효과 그림은 모두 pixelfx (`/fxlab`에서 확인).

## 마법석 얻는 법 (초안)
| 단계 | 얻는 법 |
|---|---|
| Ⅰ | 작업대: 광석 2 + 꽃 1 + 속성 재료 1 (불=목재, 얼음=물고기, 번개=광석, 빛=꽃, 자연=풀, 시공=별조각) |
| Ⅱ | 같은 속성 Ⅰ 3개 + 비석에서 수학 문제(보통) 맞히기 |
| Ⅲ | 같은 속성 Ⅱ 2개 + 어려운 문제 · 하루 1번 |
| 합체 | 두 속성 Ⅱ를 하나씩 |

## 숨은 속성 (아래로 열리는 트리)
필요한 속성의 **궁극기(Ⅲ)를 모두** 배우면 스킬 트리 아래쪽에 새 트리가 열려요. (합체 마법 칸은 이걸로 바뀜)
- **처음엔 아래쪽이 아예 안 보임.** 숨은 속성이 하나라도 열리면 그때 아래쪽이 나타남.
- 열리는 조건은 게임 안에서 **안 알려 줌** (못 연 숨은 속성은 `???`로만 보임) → 학생들이 직접 찾아내는 재미.
- 색: 물 = 파랑, 독 = **보라**, 어둠 = **검정**(테두리만 연보라), 시공 = 흰색. 블랙홀은 검보라.

| 숨은 속성 | 열리는 조건 | Ⅰ | Ⅱ (둘 중 하나) | Ⅲ |
|---|---|---|---|---|
| 💧 물 | 불 Ⅲ + 얼음 Ⅲ | 물방울: 밭에 물 주기 (작물 +10%) | 물대포: 멀리 물을 뿜어 밀어내기 / 물의 고리: 내 둘레 덫 씻어내기 | 해일: 큰 물결이 휩쓸기 |
| ☠ 독 (보라) | 자연 Ⅲ + 얼음 Ⅲ | 독 포자: 침입자 느리게 | 독구름: 우리 땅에 독구름 남기기 / 산성 튀기기: 방벽·바위 녹이기 | 독 늪: 오래 남는 늪으로 길 막기 |
| 🌑 어둠 (검정) | 빛 Ⅲ + 번개 Ⅲ + 불 Ⅲ | 그림자: 밤에 내 모습이 흐려짐 (잠입) | 영혼 흡수: 쓰러진 자리에서 재료 거두기 / 분해: 설치물 부숴 재료로 돌려받기 | 블랙홀: 주변을 빨아들임 |
| ✨ 시공 | 기본 6속성 Ⅲ 모두 | 마법진: 다음 수학 퀴즈 시간 +3초 | 순간이동: 앞으로 4칸 / 별똥별: 재료가 떨어짐 | 시간 정지: 수도 귀환 · 잠깐 시간이 멈춤 |

- 물·어둠의 해일·블랙홀은 pixelfx 효과의 **색만 바꿔서** 씀 (얼음 → 파랑 물, 빨아들이는 폭발 → 검보라).
- 시공은 모든 속성을 끝까지 배운 사람만 → 게임 끝 무렵 "전설" 느낌.

## 정할 것
- 숨은 속성 열리는 조건이 너무 어렵지 않은지 (궁극기 = 하루 1번 마법석 Ⅲ)
- 마법석 얻는 법 (위 초안 그대로?)
- 마법 키: 2개(R·F) 걸어 두기로 충분한지
- 하루 1번 궁극기가 영역전에 주는 영향이 너무 크지 않은지

## 지금 게임에 들어간 것 (2026-11-18)
- 마법석 만들기: 작업대 ✨ 마법석 탭 (Ⅰ 재료 / Ⅱ Ⅰ×3 + 수학 문제 / Ⅲ Ⅱ×2 + 어려운 문제·하루 1번). 숨은 속성 마법석은 그 속성이 열린 사람에게만 보임
- 스킬 트리 창: 마법(K) 버튼 · K 키 → 칸 누르고 마법석 끼우기 → "R 칸에 넣기 / F 칸에 넣기"
- 마법 2칸: R / F 키, 화면 오른쪽 아래 금빛 동그라미 버튼 2개 (패드·폰은 크게), 쿨타임은 버튼이 어둡게 돌아감
- 실제 효과가 있는 마법: 꽃 피우기·물방울(밭 빨리), 바위 굴리기·산성 튀기기(산 1칸), 지진(주변 산), 불씨(빛), 순풍(빨라짐), 나뭇잎 폭풍·회오리(풀·꽃 한꺼번에 채집), 회복(익사 카운트 되돌림), 서리·얼음창(물 얼려 건너기), 순간이동(4칸), 시간 정지(수도 귀환)
- 나머지 마법은 지금은 연출만 (설명에 "(연출)") → 하나씩 효과 붙이기
- 관리자 시험용: admin api `giveBag` (이름으로 가방에 물건 넣기)
