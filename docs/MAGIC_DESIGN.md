# 마법석 스킬 트리 — 마법이 게임에서 하는 일 (초안)

- 칸 하나 = **마법석 하나**. 이름은 `불 마법석 Ⅰ`처럼 **속성 + 로마 숫자(단계)**.
  - Ⅰ = 1단계, Ⅱ = 2단계(둘 중 하나만), Ⅲ = 궁극기
- 마법석을 칸에 **끼우면** 그 마법을 배움. Ⅰ은 3개까지 끼워 강화(효과 커짐).
- 지금은 **플레이어끼리 싸우기 꺼짐** → 모든 마법은 **생활·채집·나라 돕기** 효과로 시작.
  "싸움 켜면" 칸은 나중에 싸움(X1)을 켤 때 덧붙일 효과.
- 키: 배운 마법 중 2개를 골라 **R / F** 키(패드는 동그라미 버튼)에 걸어 둠.
- 효과 그림은 모두 pixelfx (`/fxlab`에서 확인).

## 마법석 얻는 법 (초안)
| 단계 | 얻는 법 |
|---|---|
| Ⅰ | 작업대: 광석 2 + 꽃 1 + 속성 재료 1 (불=목재, 얼음=물고기, 번개=광석, 빛=꽃, 자연=풀, 시공=별조각) |
| Ⅱ | 같은 속성 Ⅰ 3개 + 비석에서 수학 문제(보통) 맞히기 |
| Ⅲ | 같은 속성 Ⅱ 2개 + 어려운 문제 · 하루 1번 |
| 합체 | 두 속성 Ⅱ를 하나씩 |
