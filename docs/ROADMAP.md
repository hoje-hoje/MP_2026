# MP 이세계 — 아이디어 정리와 개발 일정 (11/13 작성)

원칙: **영역전이 메인 이벤트.** 모든 서브 콘텐츠의 결과는 결국 **병력**으로 이어진다.
평화로운 것(마을 꾸미기·농사·음악)도 있어야 추억이 된다.

## 1. 지금까지 만든 것 (1단계 끝)
- 영역전 규칙서 전부 (전선 2k+1, 최소 20%, 왕만 선포·방어, 30분 마감, 동시 2나라·2번, 충원 10%, 1.1배·동점 방어승, 란체스터 손실, 영역 일부 이전, 재료 10%, 포로 10%, 멸망→유랑민)
- 천도, 건국·점령(스도쿠·슬라이딩), 잠입·약탈·감옥·악명, 채팅 3종·말풍선·도배 방지
- 새 균열 (매일 아침 영역마다 +10%, 나라 전체 50%면 멸망, 수도 제외, 백신 = 영역 하나 0%)
- 타이틀 화면 + 여신 오프닝, 임시 효과음·배경음악
- 서버 전송량 줄이기 (150명 기준), 맵 고치기(타일·장벽·소품·스포이드·물/독물 막힘)

## 2. 스토리 (대략 — 대본은 나중에 정확히)
| 때 | 장면 |
|---|---|
| 처음 접속 | 여신이 "……어님 / ……레이어님 / 플레이어님!" 부름 → 초대 → 이름 → 세계 설명 → **MP 이세계** 로고 → 건국 (✅ 만듦) |
| 5일차 점심 | 여신 고백: "사실 여러분을 부른 것은 멸망을 막기 위해서였습니다" + 멸망 D-? 선포 |
| 5~12일차 | 맵 곳곳의 **멸망 조각** 모으기 (NPC·퀘스트·균열 땅) → 다 모이면 "악마 때문이었다" 밝혀짐 |
| 13일차 | **천사 팀 / 악마 팀** 선택 |
| 14일차 | 최종 결전 — 천사 팀이 이기면 세계는 멸망하지 않는다 |
| 15일차 (12/28) | 오프라인 부스, D-Day, 칭호 시상 (악명 최고·체포왕 등) |

## 3. 타이틀 화면
- 들어올 때마다: 로고 + 뒤에 지도 아무 곳이 천천히 흐름 + "Enter를 눌러 시작" (✅)
- 옆 메뉴: 시작하기 · 설정(배경음악·효과음) · 쿠폰 (✅)
- 처음 온 사람만 여신 오프닝 (✅)

## 4. 영역전을 웅장하게 (새 아이디어)
- 병력에 **종족**(인간·엘프·드워프)과 **무기**(검·활·지팡이…)가 있어서 전투 장면이 달라짐
- 전투 시간이 되면 화면에 **빨간 화살표 띠 + "영역전 시작"** 배너 (WARNING 대신)
- **모두가 보는 중계**: "영역전" 버튼을 누르면 지금 벌어지는 전투들을 누구나 볼 수 있음
- pixelfx 이펙트(베기·폭발·마법·화살), 전쟁 나팔 소리 (나팔 ✅)
- 정할 것: 종족·무기가 **보이기만** 하는지, **능력 차이**(예: 엘프 활 = 원거리 전선 +5%)가 있는지 / 나라마다 종족을 정하는지, 병력마다 섞는지

## 5. 서브 콘텐츠 (결과는 병력)
- 영지: 농사(심기→자라기→수확), 광물 캐기(산), 낚시, 나무 베기, 마을 꾸미기, 터렛(정비공)
- 직업 (오프라인 점심 전직, 관리자 탭): 도적(털기 2배) · 기사(수정 5번에 깸) · 마법사(방벽 빨리 부숨) · 정비공(터렛) · 농사꾼(농사 2배) · 어부(낚시 2배) · 건축업자(단단한 방벽) — 직업마다 전투 기술 하나(pixelfx)
- HP 전투: 공격·사망·부활 시간·자원 흩뿌림, 안전 지대(하늘·수도 근처)
- 동맹 (최대 3나라, 참전), 히든 NPC 퀘스트, 이름 앞 <나라명>·위 [칭호]
- 영역마다 하늘 포털 + 하늘에서 내 영토로 워프 (적 포털 안 보임), 지도·지역 이름 잘 보이게
- 캐릭터 생김새 통일 (사람형), 지도는 넓히지 않고 수도 주변을 꽉 차게
- 배경음악: 받은 음악 파일로 바꾸기
