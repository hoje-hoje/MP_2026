# 제작대 조합법 (마크처럼 3×3)

- 저장소 옆 **제작대**에서 E → 칸에 재료를 놓으면 결과가 나와요. 왼쪽 조합법을 누르면 칸에 자동으로 놓여요 (재료가 모자라면 흐린 모양만).
- 모양 그대로 놓아야 해요. 칸 안 위치는 어디든 괜찮아요.
- **건축 자재**는 나라 저장소로 들어가서, 설치 모드(G)에서 누구나 꺼내 놓아요. 도구·빛·가구는 내 가방으로.
- 글자: 목=목재 · 돌=돌 · 광=광석 · 풀=풀 · 꽃=꽃 · ·=빈칸
- 바꾸는 곳: client/rules.js 의 GRIDS · BUILD_GRIDS
