# 디자인 할 일 목록

- **UX** = 쓰는 느낌·규칙·흐름. 그림보다 먼저 **정하고** 만든다.
- **UI** = 보이는 것(그림·창·아이콘). 그림을 받아 색 맞춰 넣는다.
- 순서: **UX 먼저 → UI 나중** (규칙이 바뀌면 그림도 바뀌니까).
